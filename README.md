# QAZMARKET — Қазақ тіліндегі маркетинг зертханасы 🚀
> **«Қазақша ойла. Креативті жаса. Нарықта таныт!»**

Интерактивті веб-білім беру платформасы 10-сынып оқушылары мен оқытушыларына арналған. Қазақ тілі, заманауи маркетинг және цифрлық сауаттылықты біріктіретін commercial-grade мектеп бағдарламасы.

---

## 📌 Коммерциялық құндылығы мен мақсаты (Commercial Proposition)

* **Лицензиялық құны:** Бір сыныпқа/мектепке 40 000 – 50 000 теңге.
* **Мақсатты аудитория:** Жалпы білім беретін мектептер, гимназиялар, лицейлер, NIS және БИЛ оқушылары (10-сынып), қазақ тілі мен кәсіпкерлік пәні мұғалімдері.
* **Нәтиже:** Әрбір оқушы толыққанды **жеке цифрлық маркетингтік портфолио** (PDF) жинақтап, өз брендін, жарнамаларын, ұрандарын жасап шығарады.
* **Мұғалімдерге:** Дайын 10 күнтізбелік-тақырыптық 45 минуттық сабақ жоспары, 10 басып шығарылатын жұмыс парағы (жауап кілттерімен), бағалау критерийлері (рубрикаторлар) және сынып нәтижелерін Excel (CSV) форматында жүктеу.

---

## 🏛 Платформа құрылымы (10 Негізгі Бөлім + Басқару Панелі)

### Оқушыларға арналған модульдер (8 бөлім):
1. **Білім алаңы (`/bilim`):** Маркетинг негіздері, 4P моделі, тұтынушы психологиясы, жарнама тілі, PR және коммуникация. Әр тақырыпта:
   - Шағын теориялық конспект;
   - Терминдерді сәйкестендіру жаттығуы;
   - Интерактивті бекіту тесті;
   - Қазақша баламасын табу тапсырмасы;
   - Өзін-өзі тексеру парағы.
2. **Терминдер ойыны (`/terminder`):** Ағылшын және қазақ тіліндегі 35+ кәсіби маркетингтік терминдерді жылдам сәйкестендіру ойыны (таймер, комбо-ұпайлар, дыбыс/визуалды кері байланыс және толық 3-тілді іздеу сөздігі).
3. **Тест орталығы (`/test`):** 45+ сұрақтан тұратын үлкен деректер банкі. 10 кездейсоқ немесе 40 толық сұрақты таңдау, қателермен жұмыс және дұрыс жауап түсіндірмелері.
4. **Копирайтер зертханасы (`/copywriter`):** Жарнамалық мәтіндер мен ұрандар жазу шеберханасы. 5 қатаң критерий бойынша автоматты тексеру:
   - Ұзындығы (3–8 сөз);
   - Төл қазақ әріптерінің болуы (ә, і, ң, ғ, ү, ұ, қ, ө, һ);
   - Орысша спецификалық әріптердің болмауы (ё, ъ, ь, э, щ, ц);
   - Мәтінде бренд атауының қамтылуы;
   - Ритм және әрекетке шақыру (Call to Action).
5. **Бренд студиясы (`/brand`):** Брендтің цифрлық төлқұжатын жасау конструкторы. Атау, өнім түрі, мақсатты аудитория, бірегей түстер палитрасы, ұран, визуалды картаны тікелей PNG етіп экспорттау және портфолиоға сақтау.
6. **Жарнама жобасы (`/jarname`):** Әлеуметтік желілерге арналған жарнамалық посттар конструкторы. Instagram және Telegram форматтарындағы шынайы интерактивті мокаптар, мәтінді көшіру, сурет экспорттау.
7. **Кейстер шеберханасы (`/cases`):** Отандық және халықаралық нарықтағы 10 нақты маркетингтік кейс. Сәтсіз және ұтымды стратегияларды талдау, сарапшылық түсіндірмелер мен қорытындылар.
8. **Жеке цифрлық портфолио (`/portfolio`):** Оқушының барлық жинаған ұпайлары (XP), күн сериясы (Streak), деңгейі, бейдждер топтамасы, сақталған брендтері, ұрандары, жарнамалары мен тест тарихы. Жоғары сапалы **PDF экспорт** және баспаға жіберу.

### Мұғалімдерге арналған модульдер (2 бөлім + Кабинет):
9. **Сабақ жоспарлары (`/lesson-plans`):** 45 минуттық 10 дайын сабақ жоспары. Мақсаттары, күтілетін нәтижелері, минуттық кезеңдер кестесі, бағалау дескрипторлары және үй тапсырмасы. Мәтінді көшіру және құжат етіп жүктеу мүмкіндігі.
10. **Әдістемелік құрал және 10 жұмыс парағы (`/methodology`):** Мұғалімге арналған әдістемелік нұсқаулық, критералды бағалау рубрикаторы, әрқайсысы 10 баллдық 10 баспалық жұмыс парағы және оқытушыға ғана арналған жауап кілттері (Answer Keys).
11. **Мұғалімнің басқару панелі (`/teacher`):** Сынып коды (`10A-MARKET`), сыныптың орташа балы мен прогресі, 16 оқушының тізімі, жеке оқушы карточкасы және нәтижелерді **Excel (CSV)** форматында экспорттау.

## 🎨 Дизайн жүйесі және UI/UX ерекшеліктері

- **Қос тақырып (Dark & Light Theme):** Күлгін-көк заманауи градиенттер (`#1a1730`, `#7c3aed`, `#3b82f6`) бар қараңғы режим (референс скриншот бойынша) және жұмсақ, контрастты жарық режим. Таңдау браузердің `localStorage` жадында сақталады.
- **Тілдік қолдау (KK / RU):** Негізгі тіл — әдеби, қатесіз қазақ кириллицасы. Қосымша орыс тіліне ауысу түймесі.
- **Шрифт:** Қазақ тілінің барлық төл әріптерін толық қолдайтын `Inter` қаріптік тобы.
- **Адаптивтілік:** 360px (Mobile), 768px (Tablet), 1024px (Laptop), 1440px (Desktop) өлшемдерінде тексерілген. Мобильді құрылғыларда 44px+ ыңғайлы төменгі навигациялық тақта (Bottom Nav).
- **Қолжетімділік (Accessibility):** WCAG AA контраст талаптары, экран оқу құралдарына арналған `aria-label` белгілері, пернетақта арқылы басқару.

## 🛠 Технологиялық стек (Tech Stack)

* **Фреймворк:** [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
* **Кітапхана:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
* **Стильдеу:** [Tailwind CSS 4](https://tailwindcss.com/)
* **Компоненттер және Белгішелер:** [Lucide React](https://lucide.dev/)
* **Графиктер мен Диаграммалар:** [Recharts](https://recharts.org/)
* **Анимациялар:** [Framer Motion](https://www.framer.com/motion/)
* **Экспорт:** `html2canvas` + `jspdf`
* **Күй басқару (State):** React Context + `localStorage` persistence

## 🚀 Жобаны іске қосу (Getting Started)

### 1. Репозиторийді жүктеу және тәуелділіктерді орнату:
```bash
git clone <repository-url>
cd qazmarket
npm install
```

### 2. Әзірлеу режимінде қосу (Development Server):
```bash
npm run dev
```
Браузерде ашыңыз: `http://localhost:3000`

### 3. Өндірістік нұсқаны жинау (Production Build):
```bash
npm run build
npm run start
```

### 4. Автоматтандырылған E2E тестілеуді орындау:
```bash
node tests/run_tests.js
```
*(Барлық 39 сынақ сценарийі 100% сәтті өтеді).*

## 📂 Мазмұнды кеңейту (How to Add Content)

Платформаның барлық оқу материалдары модульдік түрде `src/data/` бумасында сақталған. Жаңа сұрақтар немесе тақырыптар қосу үшін JSON/TypeScript массивтерін толықтыру жеткілікті:

| Модуль | Файл жолы | Сипаттамасы |
|---|---|---|
| **Терминдер** | `src/data/terms.ts` | Жаңа терминдер, анықтамалар және мысал сөйлемдер |
| **Тест сұрақтары** | `src/data/questions.ts` | 4 жауап нұсқасы бар сұрақтар, дұрыс жауап индексі, түсіндірмесі |
| **Теориялық сабақтар**| `src/data/topics.ts` | 5 оқу тақырыбы (теория, жұптар, мини-тест, сұрақтар) |
| **Маркетинг кейстері**| `src/data/cases.ts` | Компаниялар тәжірибесі, шешім нұсқалары, сарапшы пікірі |
| **Копирайтер тапсырмалары** | `src/data/copywriter-tasks.ts` | Ұран жазуға арналған өнімдер, кеңестер, мысалдар |
| **Сабақ жоспарлары**| `src/data/lesson-plans.ts` | 45-минуттық кезеңдер кестесі, бағалау дескрипторлары |
| **Жұмыс парақтары**| `src/data/worksheets.ts` | Оқушы тапсырмалары мен мұғалімге арналған жауап кілттері |

## ☁️ Vercel арқылы деплой жасау (Deployment)

1. Жобаны GitHub репозиторийіне жіберіңіз:
   ```bash
   git init
   git add .
   git commit -m "feat: QAZMARKET commercial release"
   git branch -M main
   git remote add origin <your-github-repo>
   git push -u origin main
   ```
2. [Vercel](https://vercel.com) басқару тақтасында **Add New Project** түймесін басып, GitHub репозиторийін таңдаңыз.
3. Framework Preset: **Next.js** автоматты түрде танылады.
4. **Deploy** түймесін басыңыз. Жоба 1 минут ішінде жаһандық CDN арқылы іске қосылады.
